# -Pedidos_nuvemshop
## Plugin Pedidos Nuvemshop

Código do plugin na raiz do repositório. A atualização automática lê as **Releases** deste repositório.

Para publicar uma versão nova: aumente `Version` no cabeçalho de `pedidos-nuvemshop.php` e `VERSION` na classe, crie uma Release com a tag igual à versão (ex.: `v3.2.0`). Não precisa anexar zip: o WordPress baixa o código da tag.

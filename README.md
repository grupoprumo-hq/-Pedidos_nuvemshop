# -Pedidos_nuvemshop
## Plugin Pedidos Nuvemshop

Código em `pedidos-nuvemshop/`. A atualização automática lê as **Releases** deste repositório.

Para publicar uma versão nova: aumente `Version` no cabeçalho de `pedidos-nuvemshop.php` e `VERSION` na classe, gere o zip da pasta `pedidos-nuvemshop` e crie uma Release com a tag igual à versão (ex.: `v3.2.0`) anexando o zip.
